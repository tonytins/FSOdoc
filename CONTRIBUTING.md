# Contributing

If you’re interested in contributing to this project, I welcome your help! One area where you can contribute is by adding comments or documentation to the previously uncommented code that I may have overlooked. To make it easier for you, I’ve provided the same prompts I've used.

To get started, please use the following prompt in ChatGPT or any GPT-based bot that supports code:

```text
I want you to help me write draft code documentation that will be inserted in place of the former uncommented code. It needs to be formatted in Markdown and embedded in a code block for easy copying and pasting. Based on this code: [Code snippet here]
```

Then provide the previously uncommented code you want to document. The AI will generate comments or documentation for the code. Once you have the generated documentation, simply copy and paste it into the appropriate sections where the former uncommented code was.

You can continue where ChatGPT left off by providing the prompt:

```text
While omitting the rest of the already commented code, resume providing documentation comments at [...]
```

Then provide the previously uncommented code you want to document. The AI will generate comments or documentation for the code. Once you have the generated documentation, simply copy and paste it into the appropriate sections where the former uncommented code was. Your contribution will help improve the understanding and accessibility of the codebase, and I greatly appreciate your efforts in documenting the previously overlooked parts of the project.
