# FAQ

## Will FreeSOdoc branch into its own server and identity?

Ideally, yes. I have new names and logos ready in case it becomes feasible to create a separate server and identity for FreeSOdoc. However, practically speaking, it’s a complicated process. FreeSOdoc is based on old code that dates back to .NET Framework 3.5 and was originally written by another developer. Additionally, the FreeSO team, prefers to focus on their vision of the game, despite being an open source project using someone else's intellectual property. This is in stark contrast to others of similar origins that provide guidance on setting up your own server, FreeSO team’s approach is more restrictive. Nevertheless, I will continue to explore possibilities to create a separate server and identity for FreeSOdoc, taking into consideration the technical and community factors.

## What is your long-term plan for FreeSOdoc?

My long-term plan for FreeSOdoc is twofold. Firstly, I aim to document as much of the code as possible, using AI-assisted comments to make the source code more understandable and accessible. This will help users and contributors better understand the logic and functionality of the codebase, and improve the overall quality of the project.

Secondly, I plan to port over as many libraries as possible to the .NET SDK format, modernizing the codebase and ensuring compatibility with newer technologies and frameworks. This will help future-proof the project, and facilitate future development and improvements.

Additionally, I will continue to explore the possibility of creating a small server for FreeSOdoc, separate from FreeSO, in order to provide a distinct identity and experience for users.
